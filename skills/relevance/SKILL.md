# 關聯性分析技能

依研究問題與可取得的證據，分析兩個研究對象的關係及用途。預設使用繁體中文，將「與問題相關」、「符合納入條件」及「研究品質可信」分開判斷。

## 輸入

分析對象：$ARGUMENTS

可提供兩篇論文、論文與研究問題，或兩個研究問題；包含標題、DOI、摘要或全文皆可。先確認用途：背景引用、方法借鑑、結果比較，或依既定條件篩選文獻。沿用已有資訊；只追問會改變判斷且無法推知的缺項，並先完成可判斷的部分。

## 證據範圍與查核

- **只有標題／書目**：可初步定位主題，無法確認樣本、方法、測量特性或結論；相關性標為待確認。
- **有摘要**：可作初步篩選，列出摘要支持與未報告的資訊；不得把未報告寫成未執行。
- **有全文**：核對方法、樣本、工具版本、分析與結果，指出支撐判斷的章節／頁碼；全文仍不足時明列未知。
- 已有資料足夠時直接分析。需補文獻時，先確認實際可用工具；`search_papers(query, limit)` 提供跨來源搜尋，`expand_topics(seed_topic, limit)` 只產生查詢字串。目前 `deep_search(paper_doi, depth)` 是 DOI 關鍵字搜尋，不能據此宣稱兩篇互引、共同引用或已遍歷引用網絡。
- 引用關係須由參考文獻表或能提供具體引用邊的來源查證；查不到時寫「尚未確認」。搜尋可能缺摘要、隱藏來源錯誤或受索引涵蓋限制，無結果不代表無相關研究。
- 如需更新現況，記錄當次搜尋日期與範圍，依問題設定相對於當前日期的年限；保留必要的原始工具、理論與早期驗證研究，不固定排除舊文獻。

## 分析框架

只分析與任務相關的維度，每項列出「已知證據 → 關係／差異 → 未知與適用限制」。

1. **問題與構念**：研究目的、理論與概念定義是否一致？詞彙相同可能測量不同構念，詞彙不同也可能指向同一問題。
2. **目標族群與情境**：年齡、狀態、語言文化、招募場域、使用目的與時間背景是否可比？差異如何限制外推？
3. **測量與方法**：工具版本、施測方式、研究設計及分析是否回答目前的問題？方法相近可供借鑑，並不自動代表結果可合併。
4. **結果與貢獻**：可核實的結果是否支持、補充或矛盾？先確認測量、樣本與設計的可比性，再解釋差異；不要由摘要空白補造結果。
5. **文獻脈絡**：僅在已查證時呈現理論承接、引用關係或互補角色。關鍵詞、被引次數、期刊聲望與共同作者皆不能代替上述判斷。

依研究類型調整框架：介入問題可用 PICO 比較；翻譯、跨文化調適或量表研究，應比較構念、目標族群、語言／版本、使用情境及各測量特性，不勉強套用介入與對照。翻譯完成不等於效度獲證實，內部一致性也不能代表全部信效度。

需要正式測量工具評讀時，查閱 [COSMIN 官方工具與適用範圍](https://www.cosmin.nl/tools/)，依相應研究設計及可靠的全文證據分別評估內容效度、結構效度、信度、測量誤差、跨文化效度／測量恆等性等所需特性。不可用相關性、期刊或引用排名給出 COSMIN 結論；非適用工具類型須選擇相應評讀方法。

## 輸出格式

先給有條件的結論：**直接相關／部分相關／目前不相關／資料不足**，並說明對哪個研究問題或用途成立。依任務規模提供簡短段落或表格，不必逐項展開所有維度。

- 列出主要證據、差異、已知／未知及閱讀深度（標題、摘要或全文）。
- 建議具體用途：支持論點、對比結果、方法借鑑、背景補充，或待全文查核；文獻篩選須逐條對照使用者的納入／排除條件。
- 提供可核查的 DOI／URL 與必要定位，不編造書目、頁碼或引用關係。

預設不給 0–10 分。使用者明確要求分數時，說明其是依已揭示維度的主觀決策輔助，交代尺度與資訊限制；不能作為納入資格、效度、研究品質或證據確定性的替代。
