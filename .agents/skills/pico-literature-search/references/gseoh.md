# GSEOH 臺灣版搜尋與版本依據

查核日 2026-10-06。原名 **Geriatric Self-Efficacy Scale for Oral Health（GSEOH）**。Ohara et al., *Development of an oral health-related self-efficacy scale for use with older adults*, 2017;17(10):1406–1411（2016 online）。[PMID 27531046](https://pubmed.ncbi.nlm.nih.gov/27531046/)、[DOI 10.1111/ggi.12873](https://doi.org/10.1111/ggi.12873)。35 題是草案；正式 20 題、三構面。

翻譯研究應核對日文母版、構面、選項及計分，並保存個別授權與等值要求。公開題目來源可查 [KAKEN 15K20637 研究成果報告](https://kaken.nii.ac.jp/file/KAKENHI-PROJECT-15K20637/15K20637seika.pdf)；它不是原始開發期刊全文。個人通信及私人附件不隨本專案提供，不能推定已取得某位使用者的授權。

中國簡體版兩個獨立研究：

- 王晗等 2021，〈老年人口腔健康自我效能量表的漢化及信效度檢驗〉，[官方摘要](https://zhkq.cbpt.cnki.net/portal/journal/portal/client/paper/0fdd458ce79ede3ac1f939b8815e723f)，DOI `10.19749/j.cn.cjgd.1672-2973.2021.04.008`。全文需 CNKI，未自動取 PDF。
- 徐宇馨等 2021，〈老年人口腔健康相關自我效能量表的漢化及信效度檢驗〉，[官方頁](https://hlyj.suo1.cn/thesisDetails#10.12102/j.issn.1009-6493.2021.16.007&lang=zh)，DOI `10.12102/j.issn.1009-6493.2021.16.007`。既有官方 PDF 重新讀取確定英文版漢化、南京社區樣本；可作對照，不替代日文母版。

兩篇中文期刊需補查官方中文來源；題名有／無「相關」，含簡體「相关」「汉化」「信效度检验」。使用研究可當背景，不當翻譯驗證。

[Wu 2022 BMJ Open protocol，PMID 35732396](https://pubmed.ncbi.nlm.nih.gov/35732396/) 有 slightly modified six-item GSEOH，屬改編使用，不直接當標準簡版獨立驗證。西語 OHSES-7Sp、OHSE、SESS、GOHAI／OHIP 為其它工具；[OHSES 原研究](https://doi.org/10.1186/s12903-024-03889-4) 引用 GSEOH 不等於其西語版本。

臺灣版在前次限定來源未發現公開證據不等於不存在。不能以今天 name + Taiwan 查不到宣稱排他性新穎。若問研究缺口，另查臺灣學位論文、期刊、典藏及進行中研究，保留範圍與日期。
